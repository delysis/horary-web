## Files

- Each family Markdown file contains every full question, its full saved answer and reasoning when available, then a clearly separate rubric.
- `answers/<type>.jsonl` contains only case IDs, original splits and the five worked-answer fields. Rubric prose is not stored in the answer fields.
- `contexts/<type>.jsonl` contains the corresponding declared consultation and complete calculated chart evidence, so evidence IDs in the answer can be inspected. These are review records, not the compact student prompt.
- `provenance/<type>.jsonl` binds the saved answer hash, book/page witnesses and recorded model-review dimensions. No book excerpts, teacher prompts, credentials or account configuration are published.
- [Original case banks](../examples) preserve full questions, authored device/chart anchors, expected extraction facts and separate rubrics. Neither those private expected fields nor the reference answer should be fed as live student input.
- `manifest.json` lists exact coverage and missing case IDs.
